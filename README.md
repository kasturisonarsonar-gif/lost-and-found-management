# Lost and Found Management System (Flask + SQLite)

## Run
    pip install -r requirements.txt
    python app.py
Open http://127.0.0.1:5000

Admin login: admin@lf.com / admin123

## Features
- Register / login (hashed passwords)
- Report lost or found items with photo
- Search and filter by keyword, type, category
- Possible matches (same category, opposite type)
- Claim an item with proof; admin approves or rejects
- Admin dashboard with stats, claims and item management
